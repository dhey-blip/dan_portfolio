Capstone Project

Wheel'em POS & Inventory System

Project Overview

A web-based Point-of-Sale and Inventory Management System built for Wheel'em Clothing Line, covering sales, inventory, products, user roles, reporting, and forecasting in one system.

Objective

To design and develop a POS and inventory system for Wheel'em Clothing Line that streamlines sales transaction processing with support for multiple payment options, enables real-time inventory tracking with automatic stock deduction, and produces consistent, timely sales and inventory reports — incorporating machine-learning-based forecasting to improve demand prediction and stock management.

Problem

The capstone was guided by the following research questions:

  • What were the existing procedures and key challenges in processing customer purchases, tracking inventory (including size, color, and style variations), and generating accurate, real-time sales and inventory reports?
  • What core features would resolve those issues — including streamlined transaction processing with multiple payment options (cash, GCash), real-time inventory tracking with automatic stock deduction, and consistent reporting with restocking alerts?
  • What software development methodology would best support the system's scalability, adaptability, and responsiveness?
  • What machine learning algorithm would improve sales and inventory forecasting accuracy?
  • How acceptable is the developed system based on ISO/IEC 25010:2011 software quality standards — functionality, performance efficiency, compatibility, usability, reliability, security, maintainability, and portability?

Solution

A single system that handles point-of-sale transactions with support for multiple payment options (cash and GCash), tracks inventory in real time across product variants (size, color, style) with automatic stock deduction, enforces role-based access for Owner, Cashier, and Stocker accounts, and applies machine-learning-based forecasting to historical sales data. The system's quality was evaluated against ISO/IEC 25010:2011 standards.

Features

  • Point-of-sale transactions & receipt generation, with support for multiple payment options (cash, GCash)
  • Inventory management with real-time stock updates and low-stock notifications
  • Product & product variant management (size, color, style)
  • Role-based access — Owner, Cashier, Stocker
  • Activity logging
  • Sales reporting — daily, monthly, top products, payment distribution
  • Sales forecasting — Linear Regression
  • Inventory forecasting — Random Forest
  • Configured discount & VAT handling (Senior Citizen 20%, PWD 20%, Solo Parent 10%, VAT 12%)

Technology Stack

HTMLTailwind CSSJavaScript Chart.jsPHPMySQL PythonXAMPP

Forecasting

Forecasting uses Python, trained on historical manual transaction data from 2021–2024 and system-generated transactions beginning in 2025. Sales forecasting uses a Linear Regression model; inventory forecasting uses a Random Forest model. Results are visualized with Chart.js.

Development

My role on this capstone was full-stack developer — I worked across both the frontend interfaces and the backend application logic to bring the system together.

Subject Project

SecureEntry

Project Overview

SecureEntry is a Django web application built around QR codes: it generates a unique QR code for each entry record and reads that code back through a camera to verify it, logging the activity along the way.

Objective

Built to fulfill a course/subject requirement, with a personal focus on exploring QR code generation and scanning as a practical, hands-on application of the Django framework.

Problem

Since this project used a language and framework (Django) that were new, a key part of the challenge was learning Django hands-on while building the system, rather than applying prior experience with it.

Solution

Each entry gets a generated QR code (via the qrcode library) that's stored and later decoded using OpenCV and pyzbar for camera-based scanning. Verified entries trigger automated email notifications through SendGrid, get written to an audit log, and are visible through an admin dashboard.

Features

  • QR code generation for entry records
  • Camera-based QR code scanning & verification
  • Automated email notifications (SendGrid)
  • Audit / activity logging
  • Admin dashboard for managing entries
  • PDF generation (ReportLab)
